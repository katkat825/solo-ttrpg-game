# minis/

Single recordings of a weighted figure being **set down** on the mat — the sound B1 asks for
(`THE_BOARD.md`), and one of `THE_TABLE.md` §7's first-order table sounds.

**This folder is empty of samples, and `MiniVoice` knows it.** Until a recording lands here it
borrows `impacts/wood/` and pitches it down — the same borrowing `Tray/skins/surfaces/felt.tres`
does, and labelled in the same way so it is findable. Drop a `.wav` in here and `MiniVoice`
switches to it with no code change: **the folder is the list**, exactly as it is for impacts.

Naming follows the impacts rule — **named for what is struck, not for what strikes it**. These
are figures on a mat, so the eventual sibling folders are by surface, not by miniature.

Sourcing and slicing: same route as the impacts, `tools/slice_impacts.py`, provenance in
`THIRD_PARTY.md`.
